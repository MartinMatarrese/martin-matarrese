# Porfolio Profesional - Martin Matarrese  

## Descripción

Porfolio profesional que muestra mis habilidades como **Desarrollador full Stack** especializado en **React.js**, **Node.js**, **SQL** y **Testing QA Manual**. El sitio presenta mis proyectos, certificaciones y experiencia de manera elegante y responsiva.

## Características Principales 

### **Diseño moderno**
- Interfaz oscura con gradientes elegantes
- Totalmente responsivo (mobile-first)
- Animaciones suaves y transiciones
- Tipografía Inter para mejor legibilidad

### **Tecnologías implementadas**
- **Frontend:** React.js, CSS3, React Router

### **Experiencia de usuario**
- Navegación intuitiva con scroll suave
- Secciones interactivas (carruseles)

## Instalación local

Si deseas ejecutar este proyecto localmente:

1. Clonar el repositorio

    ```bash
    git clone https://martinmatarrese.github.io/martin-matarrese/
    cd martin-matarrese
    ```
2. Instalar dependencias

    ```bash
    npm install
    ```
3. Ejecutar la aplicación

    ```bash
    npm start
    ```
4. Abrir el navegador
    ```bash
    http://localhost:3000
    ```
